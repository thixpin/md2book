# အခန်း (၃) - List နှင့် Dictionary

တန်ဖိုး တစ်ခုတည်းကို သိမ်းတာထက် တန်ဖိုး *အများအပြား* ကို တစ်စုတစ်စည်းတည်း သိမ်းဖို့ လိုတာများပါတယ်။ Python မှာ ဒီအတွက် **list** နဲ့ **dictionary** ကို အသုံးအများဆုံးပါ။

## List

List ဆိုတာ အစီအစဉ်လိုက် စီထားတဲ့ တန်ဖိုးတွေ ဖြစ်ပါတယ်။ Square bracket `[ ]` ထဲမှာ comma နဲ့ ခွဲရေးပါတယ်။

<!-- include: collections_demo.py#fruits -->

### List ရဲ့ အခြေခံ လုပ်ဆောင်ချက်များ

- `append(x)` — နောက်ဆုံးမှာ ထပ်ထည့်
- `insert(i, x)` — နေရာ `i` မှာ ထည့်
- `remove(x)` — တန်ဖိုး `x` ကို ဖယ်
- `len(items)` — အရေအတွက်

#### Index နဲ့ ယူခြင်း

1. ပထမဆုံး တန်ဖိုးက `fruits[0]` ပါ။
2. နောက်ဆုံး တန်ဖိုးက `fruits[-1]` ပါ။
3. အပိုင်းတစ်ခုကို `fruits[1:3]` နဲ့ ယူနိုင်ပါတယ်။

> [!NOTE]
> List ထဲမှာ အမျိုးအစား မတူတဲ့ တန်ဖိုးတွေ ရောထည့်လို့ ရပေမယ့် တစ်မျိုးတည်း ထားတာက ဖတ်ရလွယ်ပါတယ်။

## Dictionary

Dictionary က *key* နဲ့ *value* အတွဲတွေကို သိမ်းပါတယ်။ Key တစ်ခုနဲ့ သူ့ value ကို ချက်ချင်း ရှာနိုင်ပါတယ်။

<!-- include: collections_demo.py#prices -->

```console
$ python3 collections_demo.py
သရက်: 1,500 ကျပ်
ငှက်ပျော: 500 ကျပ်
ဒူးရင်း: 12,000 ကျပ်
```

| လုပ်ဆောင်ချက် | ရေးပုံ | ရလဒ် |
|---|---|---|
| ယူခြင်း | `prices["သရက်"]` | `1500` |
| ထည့်ခြင်း | `prices["မင်းကွတ်"] = 3000` | key အသစ် |
| ရှိမရှိ စစ်ခြင်း | `"သရက်" in prices` | `True` |
| ဖယ်ခြင်း | `del prices["သရက်"]` | key ပျောက် |

> [!WARNING]
> မရှိတဲ့ key ကို `prices["ပန်းသီး"]` လို ယူရင် `KeyError` ဖြစ်ပါတယ်။ စိတ်မချရင် `prices.get("ပန်းသီး", 0)` ကို သုံးပါ။

> [!TRY]
> သင်ကြိုက်တဲ့ အသီး သုံးမျိုးနဲ့ ဈေးနှုန်းကို dictionary တစ်ခု ဖန်တီးပြီး စုစုပေါင်းကို တွက်ကြည့်ပါ။
