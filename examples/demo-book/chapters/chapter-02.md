# အခန်း (၂) - Data အမျိုးအစားများ

Program တစ်ခုက လုပ်သမျှ အလုပ်အားလုံးဟာ data နဲ့ ပတ်သက်ပါတယ်။ စာသား၊ ဂဏန်း၊ မှန်/မှား တန်ဖိုး စတာတွေကို သိမ်းမယ်၊ ပြောင်းမယ်၊ နှိုင်းယှဉ်မယ်။ Python က data တစ်ခုချင်းစီကို **အမျိုးအစား (type)** တစ်ခုနဲ့ သိမ်းထားပြီး ဒီအမျိုးအစားက အဲဒီ data နဲ့ ဘာတွေ လုပ်လို့ရလဲ ဆိုတာကို ဆုံးဖြတ်ပါတယ်။

ဒီအခန်းမှာ နေ့စဉ် အသုံးအများဆုံး အမျိုးအစားတွေကို တစ်ခုချင်း ကြည့်သွားပါမယ်။ ပြီးရင် အမျိုးအစား တစ်ခုကနေ တစ်ခုကို ဘယ်လို ပြောင်းရလဲ၊ ဘယ်နေရာမှာ အမှားဖြစ်တတ်လဲ ဆိုတာကိုပါ လေ့လာပါမယ်။

## အခြေခံ အမျိုးအစားများ

Python မှာ ပါပြီးသား (built-in) အမျိုးအစား အများကြီး ရှိပေမယ့် အခုအချိန်မှာ သိထားရမှာက ဒီလေးမျိုးပါ။

| အမျိုးအစား | ဥပမာ | အသုံးပြုပုံ |
|---|---|---|
| `int` | `42`, `-7` | ရေတွက်ခြင်း၊ အကြိမ်ရေ |
| `float` | `3.14`, `0.5` | အလေးချိန်၊ ဈေးနှုန်း တွက်ချက်မှု |
| `str` | `"မင်္ဂလာပါ"` | စာသား၊ အမည်၊ လိပ်စာ |
| `bool` | `True`, `False` | အခြေအနေ စစ်ဆေးခြင်း |

တန်ဖိုးတစ်ခုရဲ့ အမျိုးအစားကို `type()` နဲ့ စစ်ကြည့်နိုင်ပါတယ်။

```console
$ python3
>>> type(42)
<class 'int'>
>>> type("မင်္ဂလာပါ")
<class 'str'>
>>> type(3.14)
<class 'float'>
```

## ဂဏန်းများ

### Integer (`int`)

`int` က ဒသမ မပါတဲ့ ကိန်းပြည့်တွေပါ။ Python ရဲ့ integer တွေမှာ အရွယ်အစား ကန့်သတ်ချက် မရှိပါဘူး။ Memory ရှိသလောက် ကြီးတဲ့ ဂဏန်းကို သိမ်းလို့ရပါတယ်။

```python
population = 54_000_000      # underscore ဖြင့် ဖတ်ရလွယ်အောင် ခွဲနိုင်သည်
big = 2 ** 100
print(big)                   # 1267650600228229401496703205376
```

### Floating point (`float`)

`float` က ဒသမ ပါတဲ့ ဂဏန်းတွေပါ။ ကွန်ပျူတာက ဒသမ ဂဏန်းတွေကို binary ပုံစံနဲ့ သိမ်းတဲ့အတွက် တချို့ တန်ဖိုးတွေဟာ အတိအကျ မဟုတ်ဘဲ အနီးစပ်ဆုံး တန်ဖိုးသာ ဖြစ်ပါတယ်။

```python
print(0.1 + 0.2)             # 0.30000000000000004
print(0.1 + 0.2 == 0.3)      # False
```

> [!WARNING]
> `float` တန်ဖိုးများကို `==` ဖြင့် တိုက်ရိုက် မနှိုင်းယှဉ်ပါနှင့်။ `math.isclose()` ကို သုံးပါ၊ ငွေကြေး တွက်ချက်မှုအတွက်ဆိုရင် `decimal.Decimal` ကို သုံးပါ။

```python
import math
from decimal import Decimal

print(math.isclose(0.1 + 0.2, 0.3))           # True
print(Decimal("0.10") + Decimal("0.20"))      # 0.30
```

### ဂဏန်း operator များ

| Operator | အဓိပ္ပာယ် | ဥပမာ | ရလဒ် |
|---|---|---|---:|
| `+` | ပေါင်း | `7 + 2` | 9 |
| `-` | နုတ် | `7 - 2` | 5 |
| `*` | မြှောက် | `7 * 2` | 14 |
| `/` | စား (ရလဒ် float) | `7 / 2` | 3.5 |
| `//` | စား (ကိန်းပြည့်) | `7 // 2` | 3 |
| `%` | အကြွင်း | `7 % 2` | 1 |
| `**` | ထပ်ကိန်း | `7 ** 2` | 49 |

`/` က အမြဲတမ်း `float` ပြန်ပေးတယ် ဆိုတာ သတိထားပါ။ ကိန်းပြည့် ရလဒ် လိုချင်ရင် `//` ကို သုံးရပါမယ်။

## စာသား (`str`)

စာသားကို single quote (`'...'`) ဒါမှမဟုတ် double quote (`"..."`) နဲ့ ရေးပါတယ်။ Python 3 ရဲ့ string တွေဟာ Unicode ဖြစ်တဲ့အတွက် မြန်မာစာကို ဘာပြဿနာမှ မရှိဘဲ သုံးလို့ရပါတယ်။

```python
name = "အောင်အောင်"
city = 'ရန်ကုန်'
greeting = f"မင်္ဂလာပါ {name}၊ {city} က ကြိုဆိုပါတယ်။"
print(greeting)
```

### String ကို ခွဲခြင်းနှင့် ဆက်ခြင်း

String တစ်ခုရဲ့ အစိတ်အပိုင်းကို index နဲ့ ယူနိုင်ပါတယ်။ Index က `0` ကနေ စပါတယ်။ အနုတ် index က နောက်ဆုံးကနေ ပြန်ရေတွက်ပါတယ်။

```python
word = "Python"
print(word[0])      # P
print(word[-1])     # n
print(word[0:3])    # Pyt
print(word + "!")   # Python!
print(word * 2)     # PythonPython
```

> [!NOTE]
> မြန်မာစာမှာ စာလုံးတစ်လုံးဟာ Unicode character တစ်ခုထက် ပိုနိုင်ပါတယ်။ ဥပမာ "ကျွန်" မှာ character ငါးခု ပါပါတယ်။ ဒါကြောင့် `len("ကျွန်")` က `5` ပြန်ပေးပြီး `word[0]` က "က" တစ်လုံးတည်းကိုသာ ပြန်ပေးပါမယ်။

### အသုံးများသော string method များ

| Method | လုပ်ဆောင်ချက် | ဥပမာ |
|---|---|---|
| `upper()` | စာလုံးကြီး ပြောင်း | `"py".upper()` → `"PY"` |
| `strip()` | အစ/အဆုံး space ဖယ် | `"  a ".strip()` → `"a"` |
| `split()` | စာသားကို ခွဲ | `"a,b".split(",")` → `["a", "b"]` |
| `replace()` | အစားထိုး | `"cat".replace("c", "b")` → `"bat"` |
| `startswith()` | အစကို စစ် | `"python".startswith("py")` → `True` |

## မှန်/မှား (`bool`)

`bool` မှာ တန်ဖိုး နှစ်ခုပဲ ရှိပါတယ်: `True` နဲ့ `False`။ နှိုင်းယှဉ်မှု တွေရဲ့ ရလဒ်ဟာ `bool` ဖြစ်ပါတယ်။

```python
age = 20
print(age >= 18)             # True
print(age > 18 and age < 30) # True
print(not age == 20)         # False
```

Python မှာ တန်ဖိုး တိုင်းကို `True`/`False` အဖြစ် စစ်လို့ရပါတယ်။ `0`၊ `0.0`၊ `""` (string အလွတ်)၊ `None` တို့ဟာ `False` လို့ ယူဆပြီး ကျန်တာ အားလုံး `True` ဖြစ်ပါတယ်။

```python
name = input("နာမည် ထည့်ပါ: ")
if name:
    print(f"မင်္ဂလာပါ {name}")
else:
    print("နာမည် မထည့်ရသေးပါ။")
```

## `None`

`None` က "တန်ဖိုး မရှိသေးဘူး" ဆိုတာကို ပြတဲ့ အထူးတန်ဖိုး ဖြစ်ပါတယ်။ Function တစ်ခုက ဘာမှ `return` မလုပ်ရင် `None` ကို ပြန်ပေးပါတယ်။ `None` ကို စစ်တဲ့အခါ `==` အစား `is` ကို သုံးပါ။

```python
result = None
if result is None:
    print("ရလဒ် မရှိသေးပါ။")
```

## အမျိုးအစား ပြောင်းခြင်း

တစ်ခါတစ်ရံ တန်ဖိုးတစ်ခုကို အမျိုးအစား တစ်ခုကနေ တစ်ခုကို ပြောင်းဖို့ လိုပါတယ်။ အထူးသဖြင့် `input()` က အမြဲတမ်း `str` ပြန်ပေးတဲ့အတွက် ဂဏန်းအဖြစ် သုံးချင်ရင် ပြောင်းရပါမယ်။

```python
text = input("အသက် ထည့်ပါ: ")   # "25"
age = int(text)                  # 25
price = float("1500.50")         # 1500.5
label = str(42)                  # "42"
```

ပြောင်းလို့ မရတဲ့ တန်ဖိုးကို ပြောင်းရင် `ValueError` ဖြစ်ပါတယ်။

```console
$ python3
>>> int("၂၅")
25
>>> int("twenty")
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
ValueError: invalid literal for int() with base 10: 'twenty'
```

> [!TRY]
> `int("၂၅")` က `25` ကို ပြန်ပေးတာ သတိပြုပါ။ Python က မြန်မာ ဂဏန်းတွေကိုလည်း ဂဏန်းအဖြစ် နားလည်ပါတယ်။ `float("၃.၁၄")` ကိုလည်း စမ်းကြည့်ပါ။

### ပြောင်းလဲမှု အကျဉ်းချုပ်

| မှ | သို့ | Function | သတိပြုရန် |
|---|---|---|---|
| `str` | `int` | `int("42")` | ဂဏန်းမဟုတ်ရင် `ValueError` |
| `str` | `float` | `float("3.5")` | ဒသမ အမှတ် `.` သာ လက်ခံ |
| `float` | `int` | `int(3.9)` | ဒသမကို ဖြတ်ချ (`3`)၊ လုံးမပေး |
| `int` | `str` | `str(42)` | အမြဲ အောင်မြင် |
| any | `bool` | `bool(x)` | `0`၊ `""`၊ `None` → `False` |

## လေ့ကျင့်ခန်း

အောက်ပါ program က ဈေးနှုန်းနဲ့ အရေအတွက်ကို ဖတ်ပြီး စုစုပေါင်းကို တွက်ပါတယ်။ Input တွေကို မှန်ကန်တဲ့ အမျိုးအစား ပြောင်းထားတာ သတိပြုပါ။

```python
price = float(input("ဈေးနှုန်း: "))
quantity = int(input("အရေအတွက်: "))
total = price * quantity
print(f"စုစုပေါင်း: {total:,.2f} ကျပ်")
```

```console
$ python3 total.py
ဈေးနှုန်း: 1500
အရေအတွက်: 3
စုစုပေါင်း: 4,500.00 ကျပ်
```
