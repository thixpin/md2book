# အခန်း (၁) - Python ကို ထည့်သွင်းခြင်း

Python သည် လေ့လာရ လွယ်ကူသော programming language တစ်ခု ဖြစ်သည်။ ဤအခန်းတွင် ကွန်ပျူတာ၌ Python ထည့်သွင်းပုံကို လေ့လာပါမည်။

## ထည့်သွင်းခြင်း

Terminal ကို ဖွင့်ပြီး version ကို စစ်ကြည့်ပါ။

```console
$ python3 --version
Python 3.13.1
```

> [!NOTE]
> Python 3.10 နှင့် အထက် ဗားရှင်းကို အသုံးပြုရန် အကြံပြုပါသည်။
