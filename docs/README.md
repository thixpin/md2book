# md2book documentation

md2book turns a Markdown book manuscript into a print-ready PDF, an
EPUB 3, a web edition and a QA report, with first-class support for
Myanmar (Burmese) script.

## Guides

- [Getting started](getting-started.md): install md2book and build a
  first book, step by step.
- [Writing chapters](writing.md): chapter files, headings, parts, code
  includes and the closing image.
- [Markdown syntax](markdown.md): everything chapters can use, and
  what they cannot.
- [Covers](cover.md): design a cover in HTML and CSS and render it to a
  PNG with the book's fonts.
- [Usage examples](examples.md): recipes for common jobs, from a
  Myanmar book to a print-shop PDF and a published web edition.
- [Analytics](analytics.md): count readers of the web edition with
  Google Analytics, Plausible, GoatCounter or Cloudflare.

## Reference

- [Commands](commands.md): every `md2book` command and option.
- [Configuration](configuration.md): every `book.json` key.
- [Editions](editions.md): what the PDF, EPUB, web edition and QA report
  contain and where they are written.
- [Fonts](fonts.md): the font sets, the cache and offline use.
- [Programmatic API](api.md): the same commands as functions for
  Node.js.
